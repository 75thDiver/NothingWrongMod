# Stage 0 Migration Implementation Plan

> **For agentic workers:** при реализации использовать пошаговое выполнение; на этапе 0 не запускать параллельных исполнителей, пока baseline не установлен.

**Goal:** создать единую воспроизводимую исходную точку `0.27-enginefix3-candidate` без изменения игрового содержимого.

**Architecture:** активный мод находится в корне workspace; `DESIGN/` хранит канон и отчёты, `tools/` — read-only проверки, Git фиксирует baseline. Архив служит только источником проверки и не является второй рабочей сборкой.

**Tech Stack:** HOI4 1.19.*, Paradox script, Python 3.10+ без внешних зависимостей, Git.

**Spec:** `DESIGN/PREALPHA_ROADMAP.md`

## Global Constraints

- Не изменять игровые файлы и карту в ходе миграции.
- Не считать статические проверки игровым запуском.
- Сохранять защищённые prerequisites России 0.27.2.
- Не устанавливать внешние зависимости.

## Review Focus

- Активная папка должна полностью совпадать с выданным enginefix3.
- Внешний и внутренний descriptor должны сообщать одну версию.
- Валидатор должен работать из текущего корня, а не ожидать вложенный `NothingWrongMod/`.
- Git baseline не должен включать временные логи, кэши и резервные копии.
- Карта и игровой код должны остаться неизменными.
