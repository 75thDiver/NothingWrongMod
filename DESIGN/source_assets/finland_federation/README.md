# Ранее рассмотренный финско-шведский вариант

Источник: https://commons.wikimedia.org/wiki/File:Flag_of_Sweden_and_Finland.png

Автор: Eintracht4ever. В метаданных Commons указано Public domain (PD-self). Исходник и три производных TGA сохранены только как история сравнения.

13 ноября 2026 года владелец оценил этот вариант как неудачный; он не используется игровым тегом. Текущий нарисованный флаг `NW_FINNISH_FEDERATION` вдохновлён опубликованным на Reddit финско-шведским скандинавским крестом. Reddit-изображение не включено в мод, поскольку его публикация не указывает лицензию. См. `reddit_sweden_finland_union.md` и генератор `tools/create_finland_federation_flag.py`.
