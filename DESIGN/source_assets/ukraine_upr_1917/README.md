# Ukrainian People's Republic alternate flag

This asset reproduces the yellow-over-blue bicolor shown on Wikimedia Commons as the non-official UPR flag used occasionally before March 1917. The Commons file description lists yellow `#FFCD00` and light blue `#78B4FF`. It is an alternative historical variant, not the official state flag adopted later.

Source: https://commons.wikimedia.org/wiki/File:Flag_of_Ukrainian_People%27s_Republic_(non-official,_1917).svg
Vexillology discussion/reference: https://www.reddit.com/r/vexillology/comments/wvq4mp/alternative_flag_flown_by_ukrainian_peoples/

The SVG in this folder is a format-safe reproduction of the two-band source design. All in-game variants use the same flag so the UKR tag does not fall back to the vanilla flag under another ruling ideology.
