# BNR “Battle for Bialystok” spirit icon

`source.png` is the project owner's supplied image, copied byte-for-byte from the project's `.tmp` folder.

The game icon is `gfx/interface/ideas/nw14_blr_battle_bialystok.dds`. The original source remains unchanged. To make the artwork readable at the game's 60×68 icon size, the DDS uses a centered crop around the lightning split and adjacent portions of both flags (source box `(354, 330)–(900, 950)`), resized to 60×68 with LANCZOS resampling. It is uncompressed ARGB8888 and preserves the original artwork and transparency.
