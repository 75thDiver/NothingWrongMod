# Реестр State ID: Краков, Станиславов, Кельце и Львов

Этот реестр фиксирует прямое указание владельца. Он не разрешает переименовывать файлы или менять карту.

| ID | Канонический регион | Файл override | Владение в текущей сборке |

| 89 | Stanislavov / Станиславов | `history/states/89-Krakow.txt` | CZE; cores POL, UKR, CZE |

Имена файлов сохранены ради корректного override оригиналов игры и могут вводить в заблуждение. Географию определяют внутренний ID и канон владельца, а не имя файла.

По перенесённой сверке 0.26 внутренние ID и списки провинций этих четырёх файлов совпадали с предоставленными оригинальными state-файлами. Владельцы и cores являются историей мода и этой сверкой не утверждались как географическая правка.
