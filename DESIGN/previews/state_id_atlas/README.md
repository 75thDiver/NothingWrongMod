# Атлас State ID Nothing Wrong

Полный справочный атлас активных регионов HOI4. На листах подписан внутренний State ID, который нужно использовать при обсуждении карты и сценариев. В таблице рядом с ID указаны русское название, текущий владелец, файл override и лист атласа.

- index.html — обзор всех листов в одном окне.
- 00_locator.png — обзорная карта с сеткой листов A–D и 1–2.
- atlas_index.csv — точный перечень ID, названий и листов.
- maps/ — увеличенные карты, на которых подписан каждый из активных state ID.
- annotation_audit.json — автоматический отчёт о числе размещённых меток.

Плотные области разделены на дополнительные листы с буквенными суффиксами, например C1a. Ищите ID в atlas_index.csv, затем открывайте соответствующий лист.

Источник геометрии — history/states/ активной сборки и штатные файлы карты HOI4, используемые генератором проекта. Номера получены из поля id state-файла; имя файла не считается источником ID. Цвета листов нейтральные и не обозначают владельца или политический статус. Это статический справочник, не игровая карта и не изменение сценария.

Защищённые State ID 88–91 подписаны согласно канону владельца, а не согласно именам файлов или устаревшим названиям локализации.

Пересоздать атлас можно командой:

    powershell -ExecutionPolicy Bypass -File tools/annotate_state_id_atlas.ps1
